# 三分 · 五种可能 / 第一轮

2026-09-12。目标是让用户通过五个真正可操作的网站候选选择设计与内容架构。内容先沿用私人陈列，允许后续补充；这轮不替用户决定最终主站方向。

## 研究与筛选

研究以原站、工作室自己发布的案例和官方作品说明为依据。Lusion 首页另经浏览器读取与加载后截图检查。下面的“转译”是本轮设计判断，不代表原站使用了本项目相同的技术。

| 参考 | 可确认的设计线索 | 在本轮的转译 |
| --- | --- | --- |
| [Lusion](https://lusion.co/) | 原站将 3D、动效与交互叙事作为作品核心，首页有明显的场景视觉与项目入口 | 光场：一个主视觉、少量明确展品入口、切换时整场变化 |
| [Dogstudio / Vault.xyz](https://dogstudio.co/cases/vault-xyz/) | 官方案例围绕球体、涟漪、玻璃柜与网络变形展开 | 同一物件母题维系页面记忆，不照搬实时玻璃材质 |
| [Unseen World](https://unseen.co/world/) | 拖拽探索虚拟世界，内容入口被放入空间 | 漫游：内容地图、拖动、缩放、节点阅读 |
| [Bruno Simon](https://bruno-simon.com/) | 可驾驶探索的个人作品世界，地图即导航 | 空间只承担入口，始终提供可直接使用的目录 |
| [Obys](https://obys.agency/works/) | 大尺度排版、明确网格、精选作品和档案 | 索引：中文字形、列表、悬停图像、分类与网格切换 |
| [Locomotive](https://locomotive.ca/en/work) | 可分类的作品库，单个项目有独立叙事 | 保留作品、经历、念头的清楚分类与一致阅读界面 |
| [Immersive Garden](https://immersive-g.com/) | 以艺术、品牌与叙事组成的交互旅程 | 长卷：由经历而非栏目开始的滚动章节 |
| [ToyFight / LA Art Box](https://toyfight.co/work/laab) | 官方案例将强排版和动效用于引导 stories / collections | 图像、标题与正文的编辑节奏 |
| [Resn Labs](https://labs.resn.co.nz/) | 按 AR、Mobile、WebGL、AI 等组织可参与实验 | 回声：每个实验围绕一个可理解的动作 |
| [Active Theory](https://v5.activetheory.net/) | 实时空间与交互反馈；界面以作品探索为核心 | 指针扰动、形态反馈、明确的内容出口 |
| [Akaru](https://www.akaru.live/) | 序列化作品索引，并将 CSS 动画与 WebGL 能力分层 | 普通条目使用 DOM 动效，主要实验才用 Canvas |
| [Studio Freight](https://studiofreight.com/work/studio-freight) | 项目、实践与创作观点组成持续展开的作品体系 | 为画作和日常短记预留位置，避免把网站限定为完工项目集 |

筛选原则：五套需要有不同的浏览动作与内容组织；少量真实内容也能成立；中文可读；不用长加载或自动播放声音；手机尺寸有普通内容入口；后续可把喜欢的部分组合。

## 五个候选

| 候选与路由 | 核心动效 | 内容架构 |
| --- | --- | --- |
| 01 光场 `/light/` | 入场、指针视差、轻悬浮、图像与标题同步切换 | 精选展品 → 阅读室 → 下一件 |
| 02 漫游 `/atlas/` | 可拖动地图、缩放、节点悬停反馈、路径流动 | 关联地图 / 普通目录 → 节点 → 阅读室 |
| 03 索引 `/index-room/` | 字形位移、悬停揭图、条目反馈、列表与网格切换 | 分类索引 → 条目 → 下一件 |
| 04 长卷 `/journal/` | 正常滚动、章节停留、图像视差与揭示、章节导航 | 氛围封面 → 跑步 → 创造 → 放下 → 继续 |
| 05 回声 `/echo/` | Canvas 线条持续变化、指针扰动、三种形态渐变、强度调节 | 可玩的视觉实验 → 三种内容入口 → 阅读室 |

五套都提供内容目录、关于三分、原生 dialog 阅读室、Escape 关闭、关闭后焦点回到入口，以及手动暂停。减少动态效果的系统偏好在首次加载与运行中切换时都会生效。手动暂停采用禁用过渡/动画的可见最终状态，避免新阅读室被冻结在透明首帧。

## 内容边界和素材

- 真实文字依据是现有 `src/collection/`：bench-scout、两次半程马拉松、PB 1:48:37、TextLens、关于三分。没有新增经历、作品成绩或职业身份。
- 「画与视觉」「日常观察」仅为建议新增的架构位置，明确写为预留，尚未放入本人的画作或笔记。
- 现有 `static/collection/objects.jpg` 仍为 AI 概念物件图。
- `assets/chrome.jpg`、`assets/night-run.jpg` 为本轮 ImageGen 原创概念视觉，分别表达想法成形与夜跑，不是用户实物、作品原作或纪实照片。
- `assets/preview-*.jpg` 是五套实现的浏览器实测截图，用于选择页缩略图。静态图只是入口，不替代实际试玩。

## 实现与隔离

沿用仓库的 Node 环境，无新增 npm 依赖。独立 HTML/CSS/JavaScript，五套通过各自路径初始化；共享内容数据与阅读界面。Canvas 仅在回声中运行，像素比上限为 2；窄屏降低曲线数与采样密度；页面不可见或动效暂停时停止帧循环。

开发服务为 `scripts/serve-design-lab.cjs`，只监听 `127.0.0.1`。只提供试验目录、现有静态素材及已构建的现站对照页；目录穿越请求被拒绝。未更改现站源码、素材、Webpack 路由、域名或部署流程，试验目录不进入生产构建。工作分支为 `codex/motion-lab`，推送该分支不触发只监听 `main` 的 Pages 工作流。

## 验收记录

- 修改前：生产构建与现有 2 项站点测试通过。
- 完成后：生产构建与相同的 2 项站点测试再次通过；生产脚本和样式的内容散列保持不变。总览、五个路由、脚本、样式、所有配图与缩略图、本地现站对照页均返回 200；编码目录穿越请求返回 403。
- 桌面真实浏览：五套独立路由与主视觉；光场切换和阅读；漫游拖拽、复位、目录与预留页；索引分类结果（作品筛选剩 1 条）、网格切换；长卷滚动与章节直达；回声形态切换和滑块键盘输入。
- 交互回归：手动暂停后打开阅读室仍可见；暂停后光场换展品仍可见；目录 Escape 关闭和焦点返回；共享条目有下一件；通过浏览器媒体仿真验证运行中启用减少动态效果可即时暂停。
- 窄屏浏览：实际页面约 375 × 811 CSS 像素，五套检查；索引标题曾发生标点换行，已修为不换行的自适应字号；未见页面非预期水平溢出。此项为桌面浏览器窄屏模拟，不是 iPhone 真机测试。
- 修复了桌面较矮窗口中的光场按钮拥挤和回声内容入口被底部切换条遮挡。
- 触摸事件处理已实现，但内置浏览器不支持用于测试的原生触摸注入，本轮未声称完成真机触摸验收。低端手机帧率尚未实测。

下一轮依据用户实际试玩选择收敛，可选择一套，也可组合首页、切换方式与内容架构。最终站点发布须在方向明确后进行，本轮保持候选状态。
